SOFTWARE SERVICES CUSTOMER ORDER MANAGEMENT CONTROL SYSTEM

Technologies:
- Python 3.13/3.14
- MySQL 8
- mysql-connector-python

SETUP:
1. Open MySQL Workbench.
2. Run database.sql.
3. Install connector:
   pip install mysql-connector-python
4. Open each Python file and replace YOUR_PASSWORD with your MySQL password.
5. Run the programs in this order:
   program1_add_salespeople.py
   program2_add_customers.py
   program3_display_salespeople.py
   program4_increase_incentive.py
   program5_display_customers.py
   program6_city_customers.py
   program7_add_orders.py
   program8_display_orders.py
   program9_calculator.py

Run programs 1, 2 and 7 only once unless the existing records are removed first.
